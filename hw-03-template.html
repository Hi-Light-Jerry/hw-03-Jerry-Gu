Data load and preparation before modelling

gss16<-read.csv("data/gss16.csv")

Cleaning and selecting columns

gss16_advfront <- gss16 %>%
  select(advfront, emailhr, educ, polviews, wrkstat) %>%
  drop_na()

Re-levelling advfront

gss16_advfront <- gss16_advfront %>%
  mutate(
    advfront = case_when(
      advfront == "Strongly agree" ~ "Agree",
      advfront == "Agree" ~ "Agree",
      TRUE ~ "Not agree"
    ),
    advfront = fct_relevel(advfront, "Not agree", "Agree")
  )

Re-levelling polviews

gss16_advfront <- gss16_advfront %>%
  mutate(
    polviews = case_when(
      str_detect(polviews, "[Cc]onservative") ~ "Conservative",
      str_detect(polviews, "[Ll]iberal") ~ "Liberal",
      TRUE ~ polviews
    ),
    polviews = fct_relevel(polviews, "Conservative", "Moderate", "Liberal")
  )

Exercise 1: Create a linear regression model

Exercise 1 (a)

# Predict weekly email hours from years of education.
email_model <- linear_reg() %>%
  set_engine("lm") %>%
  fit(emailhr ~ educ, data = gss16_advfront)

tidy(email_model)

Therefore the fitted line is:

\[\widehat{\text{emailhr}} = -2.757 + 0.685\,\text{educ}.\]

For each additional year of education, the model predicts about 0.685 more hours spent on email per week.

The model explains about 2.9% of the variation in weekly email hours, and the residual standard error is about 10.9 hours. The residual plot shows several large positive residuals, including one of about 83 hours. Overall, years of education alone does a poor job of predicting weekly email hours.

Exercise 3: Create a workflow to fit a model

set.seed(1234)
gss16_split <- initial_split(gss16_advfront)
gss16_train <- training(gss16_split)
gss16_test  <- testing(gss16_split)

Exercise 3 (a)

# Set up the logistic regression workflow.
gss16_rec_1 <- recipe(advfront ~ educ, data = gss16_train)

gss16_mod_1 <- logistic_reg() %>%
  set_engine("glm")

gss16_wflow_1 <- workflow() %>%
  add_model(gss16_mod_1) %>%
  add_recipe(gss16_rec_1)

gss16_wflow_1

I chose logistic regression because advfront has two categories, Agree and Not agree. The model uses years of education to estimate the probability of an Agree response.

Exercise 3 (b)

# Fit the model on the training data.
gss16_fit_1 <- gss16_wflow_1 %>%
  fit(data = gss16_train)

# Predict probabilities on the test data.
gss16_pred_1 <- predict(gss16_fit_1, gss16_test, type = "prob") %>%
  bind_cols(gss16_test)

# Plot the ROC curve for Agree.
gss16_pred_1 %>%
  roc_curve(
    truth = advfront,
    .pred_Agree,
    event_level = "second"
  ) %>%
  autoplot() +
  labs(title = "ROC curve for the education model")

The ROC curve is mostly above the diagonal, but it stays fairly close to it. This suggests that years of education alone has limited ability to distinguish between Agree and Not agree responses in the test data.
